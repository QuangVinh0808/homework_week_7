# Unit test

* Đa thức modular trong trường GF2^4: m(x) = x^4 + x + 1
* Đa thức modular trong trường GF2^8: m(x) = x^8 + x^4 + x^3 + x + 1

## 1. Check lookup table trong trường GF2^4 và GF2^8

| 0x00 | {0x00, 0x00, 0x00} |
| 0x01 | {0x02, 0x04, 0x08} |
| 0x03 | {0x06, 0x0C, 0x0B} |
| 0x08 | {0x03, 0x06, 0x0C} |

# Cách chạy chương trình

## Nếu muốn dùng thử
- Hãy chạy câu lệnh main.exe sau đó chọn trường cần tính rồi nhập 2 đa thức cần tính fx,gx ở dạng thập phân. Kết quả sẽ in ra ở dạng thập phân.
- Đây là bài tập mô phỏng trong trường GF4 và GF8 nên đừng nhập con số khác ngoài 4 và 8 !!!

## Nếu muốn check unit test
- Các test case đã được tính như ở trên và đã chạy trong folder tests/
- Để chạy thì chạy câu lệnh "tests/test.exe" để xem kết quả
- Nếu muốn thêm test thì vào trong file test.cpp và thêm các trường hợp vào. Chạy biên dịch "g++ tests/test.cpp -o tests/test.exe" rồi xem kết quả
